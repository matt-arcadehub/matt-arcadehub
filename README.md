## 🎮 Featured Projects

### 🔮 [Relic Lab — Unity Editor Tool](https://github.com/matt-arcadehub/Relic-Lab)

A custom Unity Editor tool for creating, previewing, and customizing stylized materials through an artist-friendly workflow.

- Developed a custom EditorWindow using C# and UI Toolkit.
- Created stylized shaders with Shader Graph, including pulsing emission and Fresnel effects.
- Implemented non-destructive material previews, presets, and material variant creation.
- Modeled three relics in Autodesk Maya and built a showcase scene in Unity URP.

**Technologies:** Unity 6, C#, UI Toolkit, Shader Graph, URP, Autodesk Maya.

### 📖 [Elixir: Hasta la última página — 2D Game](https://mattdavinci.itch.io/elixir-hasta-la-ultima-pagina)

A collaborative 2D game developed in Construct 2 and exported to HTML5.

My contributions included:

- Implemented most of the game's visual programming using Construct Event Sheets.
- Organized the project's structure, naming conventions, and directories.
- Prepared animation sequences and implemented state transitions across player and enemy actions.
- Organized audio events for music, ambience, and sound effects, with separate volume levels.

**Technologies:** Construct 2, Event Sheets, HTML5, 2D animation integration.
